# نظام إدارة المقاولات والشركاء - Musharaka Pro

نظام احترافي لإدارة مشاريع المقاولات مع الشركاء، المواد، المخازن، والتسويات المالية.

## المميزات الرئيسية

### 🏗️ إدارة المشاريع
- إنشاء وإدارة مشاريع متعددة
- ربط الشركاء بالمشاريع مع تحديد نسب الملكية
- إدارة مراحل المشروع والموازنات

### 👥 إدارة الشركاء
- نظام محافظ للشركاء (إيداع/سحب)
- توزيع التكاليف حسب الحصص أو توزيع مخصص
- تسويات دورية مع ترحيل الأرصدة

### 📦 إدارة المخزون
- إدارة الموردين والأصناف
- فواتير الشراء وحركات المخزن
- صرف المواد للمراحل مع حساب التكلفة تلقائياً

### 💰 المحاسبة والتكاليف
- تسجيل المصروفات على المراحل
- توزيع التكاليف بنظام Delta (الفرق غير الموزع فقط)
- التسويات الدورية بين الشركاء

### 📊 التقارير
- كشف حساب الشريك مع الحركات التفصيلية
- تقارير تكاليف المراحل
- تصدير التقارير إلى CSV

## التقنيات المستخدمة

- **Backend**: Flask + SQLAlchemy
- **Frontend**: Jinja2 + HTMX + Tailwind CSS
- **Database**: SQLite (افتراضي) / PostgreSQL
- **UI**: Server-rendered مع تحديثات جزئية عبر HTMX

## التثبيت والتشغيل

### التثبيت المحلي

```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل التطبيق
python run.py
```

افتح المتصفح على: http://localhost:5000

### النشر على Render

1. أنشئ حساب على [Render.com](https://render.com)
2. اربط مستودع GitHub الخاص بك
3. أنشئ Web Service جديد
4. اختر Python environment
5. أضف متغيرات البيئة:
   - `DATABASE_URL`: عنوان قاعدة بيانات PostgreSQL
   - `SECRET_KEY`: مفتاح سري للتطبيق

### متغيرات البيئة

```env
DATABASE_URL=postgresql://user:pass@host/dbname  # اختياري، SQLite افتراضياً
SECRET_KEY=your-secret-key-here                   # اختياري للإنتاج
PORT=5000                                          # اختياري
```

## الاستخدام

### البداية السريعة

1. **إنشاء مشروع**: من الصفحة الرئيسية، أدخل كود واسم المشروع
2. **إضافة شركاء**: أضف الشركاء من الصفحة الرئيسية
3. **ربط الشركاء بالمشروع**: من صفحة المشروع، اربط الشركاء وحدد نسب الملكية (المجموع 100%)
4. **إيداع في المحافظ**: قم بالإيداع في محافظ الشركاء
5. **إنشاء مراحل**: أضف مراحل المشروع مع الموازنات
6. **تسجيل المصروفات**: أضف المصروفات على المراحل
7. **توزيع التكاليف**: وزع تكاليف كل مرحلة على الشركاء
8. **التسويات**: أنشئ تسويات دورية لحساب الفروقات

### نصائح مهمة

- تأكد من أن مجموع حصص الشركاء = 100%
- قم بالإيداع في المحافظ قبل توزيع التكاليف
- التوزيع يتم فقط للتكاليف غير الموزعة (Delta)
- التسويات تحسب الفرق بين ما يجب أن يتحمله الشريك وما دفعه فعلاً
